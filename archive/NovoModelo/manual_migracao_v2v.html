Manual de Migração V2V: VMware → Proxmox

🚨 CHECKLIST CRÍTICO (Antes de começar)
Snapshots: "Delete All" no VMware. Obrigatório.
BitLocker: Desativado/Decriptado.
Espaço: Storage do Proxmox tem espaço livre > tamanho dos discos?
VM Desligada: A VM de origem está OFF?
FASE 1: Transporte dos Arquivos

Transfira os arquivos exportados (.ovf e .vmdk) para o servidor Proxmox.

Destino Obrigatório: Os arquivos devem ser colocados na pasta:
/root/migracao_temp/

Escolha seu método de transferência:

Opção A: Terminal (Rsync/SCP) Recomendado para grandes volumes.

# Exemplo usando Rsync (Executar da máquina de origem ou local) rsync -avhP /origem/arquivos/*.vmdk root@<IP_PROXMOX>:/root/migracao_temp/

Opção B: Interface Gráfica

  • Use WinSCP ou FileZilla.
  • Conecte via SFTP (Porta 22).
  • Arraste os arquivos para /root/migracao_temp/.
FASE 2: Criação da VM (Proxmox GUI)
  • Create VM: ID: 200 | Name: SRV-MIGRACAO
  • OS: Windows (Versão correta).
  • System: ✅ Qemu Agent.
  • Disks: 🗑️ DELETE o disco padrão (scsi0). Deixe VAZIO.
  • CPU: Type: Host.
  • Network: Intel E1000.
FASE 3: Importação Automática (Terminal)

Utilize o script import_vmdk.sh fornecido junto com esta documentação para evitar erros de comando.

Execução:

# Dê permissão de execução chmod +x import_vmdk.sh # Execute ./import_vmdk.sh

Siga os prompts de texto no seu terminal para inserir o ID da VM de destino e escolher o disco VMDK correto para a importação. Repita a execução para eventuais discos adicionais.

FASE 4: Estratégia "Isca" (GUI)
  1. Hardware: Dê Attach nos discos Unused como SATA.
  2. Isca: Adicione um novo disco de 1GB como SCSI (VirtIO SCSI).
  3. ISO: Monte o virtio-win.iso.
  4. Boot: Garanta que SATA0 é o primeiro boot.
FASES FINAIS: Drivers & Virada
  1. Ligue a VM → Instale drivers do CD VirtIO (Storage Controller).
  2. Valide no Gerenciador de Dispositivos (Red Hat VirtIO SCSI).
  3. Desligue a VM.
  4. Virada de Chave:
    • Remova o disco de 1GB.
    • Detach SATA → Attach SCSI (SSD Emulation + Discard).
    • Rede: Intel E1000 → VirtIO.
  5. Limpeza Automatizada: Ligue a VM. Execute o script nativo post_migration_cleanup.ps1 como PowerShell Admin. Siga as instruções listadas na tela do console exibido para remover os adaptadores antigos (ocultos) e liberar o IP antigo para sua nova interface VirtIO.
  6. Opcional Final: Desinstale o software VMware Tools pelo Painel de Controle.
